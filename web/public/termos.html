Termos de Uso — EVO MKT

O EVO MKT é um sistema interno do Colégio Evolução para organizar solicitações, tarefas, conteúdos e relatórios de marketing.

Uso

  • O acesso é pessoal, por código fornecido pela Gerência. Não compartilhe seu código.
  • Use o sistema apenas para atividades do Colégio e respeite as regras de uso das plataformas conectadas (Meta/Instagram e Google).
  • Arquivos enviados devem ser de uso autorizado pelo Colégio.

Integrações

As conexões com Instagram e Google são feitas pela Gerência com as contas do Colégio e podem ser desfeitas a qualquer momento. O Colégio é responsável pelo conteúdo publicado.

Disponibilidade

O sistema é oferecido como está, para uso interno, sem garantia de disponibilidade contínua. Mantemos backups, mas a Gerência deve conferir os dados importantes.

Veja também a Política de Privacidade.
