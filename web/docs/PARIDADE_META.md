# Paridade com o Gerenciador de Anúncios da Meta

Objetivo: fazer no EVO MKT o que se faz no Gerenciador da Meta, sem precisar abrir a Meta. Marcação: **Feito** (testado só contra o simulador da Meta), **Parcial**, **Falta**.
Nada disto foi exercitado na Meta real: o primeiro uso de cada escrita deve ser supervisionado.

| Recurso do Gerenciador da Meta | Situação | Onde |
|---|---|---|
| Lista campanhas / conjuntos / anúncios com métricas, status, orçamento | Feito | Gerenciador |
| Filtros avançados, colunas, visões salvas, exportação (CSV/Excel/PDF) | Feito | Gerenciador |
| Marcar campanhas e ver só os conjuntos/anúncios delas | Feito | Gerenciador |
| Ligar/desligar (ativar/pausar), arquivar, excluir, duplicar, lote | Feito | Gerenciador |
| Criar campanha, conjunto e anúncio separados (pausados) | Feito | + Criar |
| Criar tudo de uma vez (assistente) | Feito (nasce ativo) | + Criar › Campanha completa |
| Editar nome, orçamento, datas | Feito | Editar |
| Editar público: idade, raio, **cidade, gênero, posicionamentos, interesses, públicos personalizados** | Feito | Editar conjunto |
| Editar lance (menor custo / limite de custo) | Feito | Editar conjunto |
| Editar criativo (texto, título, descrição, link, botão) | Feito, só para anúncios de imagem com link; os de publicação do Instagram ou vídeo vêm do post | Editar anúncio |
| Detalhar por idade, gênero, plataforma, posicionamento, dispositivo, região | Feito | Painel lateral |
| Evolução por dia | Feito | Painel lateral |
| Prévia oficial do anúncio (Feed, Stories, Reels, Facebook) | Feito (iframe da Meta) | Painel do anúncio |
| Cabeçalho da conta: gasto total, limite, saldo, pagamento, estado | Feito (só leitura) | Gerenciador |
| Histórico de atividade (inclui o feito direto na Meta) | Feito | Tráfego › Histórico |
| Públicos personalizados (lista) | Parcial: só leitura | Tráfego › Públicos |
| Criar/editar públicos personalizados e semelhantes | Falta | — |
| Rascunhos de criação | Falta (existe só no assistente completo) | — |
| Edição inline na tabela (nome, orçamento) | Falta | — |
| Posicionamentos manuais por posição (feed, stories, reels…) | Parcial: só por plataforma | — |
| Teste A/B, estudos de lift, otimização por conversões personalizadas | Falta | — |
| Pixel/eventos (Gerenciador de Eventos), catálogos, formulários | Falta | — |
| Faturamento (pagar, adicionar forma de pagamento) | Fora do escopo (só a Meta) | — |
